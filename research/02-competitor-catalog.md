# Каталог конкурента (только раздел «Металлические опоры ВЛ» — /catalog-produkcii/opotyvl)

Скрапер: scratchpad/scrape.py → research/competitor/catalog.json, images/, pages/ (сырой HTML).
- 112 опор: 35 кВ — 17, 110 кВ — 44, 220 кВ — 26, 330 кВ — 10, 500 кВ — 15
- У каждой 1 изображение: **техническая схема** (линейный чертёж, размеры траверс, обозначения H, h, L) на светло-сером фоне; диагональный водяной знак «aspmk519.kz». 418×800 (35–330 кВ), 573×630 (500 кВ).
- Таблица характеристик (9–11 строк): Наименование изделия; Район по гололеду; Ветровой район; Марка провода; Размер в осях фундамента L, м; Высота опоры H, м; Высота до нижней траверсы h, м; Масса опоры с цинком, кг; Номер типового проекта; Примечание; (+ «Марка грозотроса», «Высота до низа нижн. траверсы...», «Подставка h1, м» у части).
- В исходнике символ диапазона потерян — стоит «?» («АС-70 ? АС-95»). При выводе заменяем «?» между марками на «÷» (восстановление кодировки, не правка данных). Сообщить пользователю.
- Название: «Опора П110-2». Тип по префиксу (П — промежуточная, У — анкерно-угловая, ПС/УС — с подставкой/спец., 1/2/3 — число цепей по их классификации) — НЕ интерпретируем сами; группировку берём только по разделу кВ и подкатегориям из URL (одноцепные/двухцепные, промежуточные/анкерно-угловые/ответвительные), где она есть в URL ссылок.

## Вывод для дизайна
Изображения товара = чертежи. Это идеально рифмуется с Heron (чертёж → реальность) и с бизнесом заказчика (собственный КБ, база чертежей КМД). Каталог = «чертёжный архив / линейка опор»: силуэты всех опор в реальном масштабе по H, детальная карточка = чертёжный лист с оригинальной схемой 1:1 + анимированная размерная линейка H/h/L + масштаб человека.
