# Исследование референсов (живые сайты)

Метод: Playwright (Chromium) открывает живой сайт 1440×900, скроллит колесом (чтобы срабатывали Lenis/ScrollTrigger), снимает кадры каждые ~0.85 экрана + fingerprint (GSAP/Lenis/Three/canvas/video/шрифты/цвета). Кадры: scratchpad/refs/<name>/sheet.jpg. Ниже — что взято (механика, а не дизайн).

## Главный референс
**heronaiapp.com** (BearPlus; Webflow+GSAP+Lenis+Barba, BT Grotesk + Geist Mono, off-white #F4F3EE-ish, акцент оранж-красный)
- Интро: тонкий линейный чертёж фасада «дочерчивается» → заливается в фотореалистичный рендер (линии → материя). Красная горизонтальная «отметка уровня» через весь экран.
- Мелкий моноширинный техметатекст (спецификации, координаты) как фактура интерфейса.
- Pinned-сцены: огромная фраза по центру («RIGHT THERE WITH YOU» → «FOR THE WHOLE DESIGN») — смена через затемнение/проявление, пустой экран = пауза-вдох.
- План этажа собирается стена за стеной по скроллу, затем появляются размерные линии и мебель (линейный прогресс = скролл).
- Сетка из 4 колонок с изометрическими пиктограммами «проблем», тонкие 1px разделители, номера [01].
- Футер: гигантский контурный логотип с конструктивными линиями (как чертёж шрифта).
- Почему держит: каждый скролл = видимый прогресс «строительства»; любопытство «что дорисуется дальше».
**Вывод: «чертёж → металл» — ровно наша история (КМД → опора). Берём механику, не стиль.**

## Industrial / Energy / Manufacturing
- **hadrian.co** — тёмно-синий монолит, mono-лейблы, бегущая строка в рамке. Сухо; ценно: моно-подписи к фото «OPUS: THE OPERATING SYSTEM...». Скучно по motion.
- **anduril.com** — чёрный, кинематографичные рендеры продуктов, мозаика продуктов разного размера (bento) с названием внизу слева, hover → видео. Вывод: продуктовая мозаика с ритмом размеров; большие медиа.
- **machinalabs.ai** — моно-заголовок «INTELLIGENT. AGILE. REAL METAL.» на чёрном. Слабый motion. Вывод: короткий манифест из 3 слов — сильный приём.
- **radiantnuclear.com** — Cloudflare блок (не изучен).
- **varda.com** — дуотон оранж/синий на фото (единая обработка всех фото = бренд), сетка-плитки с тонкими линиями. Вывод: единая цветовая обработка разнородных фото (у заказчика фото разного качества!) — критически полезно.
- **oklo.com** — ночная архитектурная сцена, стеклянная «капсула»-навигация, интерактивная карта проектов с точками. Вывод: карта проектов с пульсирующими точками.
- **x-energy.com** — табы «What we do» с подчёркиванием, ч/б фото лабораторий. Корпоративно.
- **basepowercompany.com** — светлый тёплый серый, шаги-аккордеон с вертикальной прогресс-линией слева, фото сменяется по шагу (sticky). Вывод: sticky-фото + линия прогресса для «процесса производства».
- **fervoenergy.com** — тёмно-синий корпоратив, карусель карточек. Банально.
- **antora.energy** — белый, крупный капс-гротеск, изометрические 3D-иконки процесса (опоры ЛЭП → блок → завод) с линией-потоком энергии, фото со срезанными углами (chamfer). Вывод: chamfer-углы = «металлический/инженерный» язык формы; процесс как цепочка с бегущей энергией.
- **terraformindustries.com** — нарочно brutalist ASCII. Не наш тон.
- **cfs.energy** (Commonwealth Fusion) — тёплый серый + тёмно-синий + оранж, mono-лейблы «● Move fast», контурный 3D-чертёж магнита наслаивается на фото. Вывод: линейная графика поверх фото = инженерная подпись.
- **helionenergy.com** — «HOW FUSION WORKS»: pinned-сцена, две светящиеся сферы сливаются по скроллу, вокруг поле топографических линий; кнопка «Skip». Вывод: пиннинг с одним объектом, который меняет состояние по скроллу — объясняет процесс без текста.
- **gevernova.com** — ч/б фото ЛЭП, condensed-капс заголовок «ENERGY OF CHANGE», лайм-акцент. Корпоратив-шаблон; нижняя планка качества для крупных энергокомпаний.
- **heirloomcarbon.com** — светлый, крупные фото индустриальных объектов с плавным parallax-сдвигом блоков (фото выезжает из-под текста). Чисто, дорого, но статично.
- **siemens-energy / hitachienergy / orsted / vestas / prysmian** — тяжёлые корпоративные порталы: карусели, cookie-модалки, ноль сторителлинга. Это фон, на котором любой сильный сайт выглядит «как из будущего» — наш шанс.
- **saronic.com** — графит + кислотный лайм, гигантский логотип в hero, продукты-карточки с фото, «Built to go where people shouldn't have to» на штормовом видео. Вывод: продукт в экстремальной среде = доказательство (у нас: Крайний Север, Певек—Билибино).
- **bostondynamics.com** — классический продуктовый портал. Ничего.
- **spacex.com** — чёрный, полноэкранное видео/фото на каждую секцию, капс-заголовок и одна кнопка, текст по краям попеременно. Вывод: минимум текста + одна мысль на экран.
- **big.dk** — чёрный интро с логотипом → вертикальная лента проектов с blur-up загрузкой. Минимализм архив-ленты.
- **snohetta.com** — белый, список проектов крупным текстом «Название — серое пояснение», hover → картинка. Вывод: каталог-список как типографика.
- **teenage.engineering** — продукт на чёрном с драматичным студийным светом, затем белые карточки товаров с тонкими разделителями; продукт как объект искусства. Вывод: «музейная» подача объекта.
- **mvrdv.com** — condensed-капс гигантские заголовки поверх фото, счётчики «277 awards», «307 creative minds» — крупные числа как сюжет.
- **polestar.com** — белый, модели в профиль на белом в сетке ячеек с 1px границами; «Find a retailer / About» гигантским текстом. **Вывод: линейка продуктов в одинаковом ракурсе на чистом фоне = каталог-витрина (у нас все опоры — фронтальные схемы!).**
- **rivian.com** — **гигантское название модели (R1S, R2, R1T) за продуктом**, продукт перекрывает буквы; при скролле буквы уезжают. Вывод: «П110-2» гигантским шрифтом за чертежом опоры в карточке.
- **koenigsegg.com** — ступенчатые (лесенкой) заголовки капсом «WHY WE / DO WHAT / WE DO». Типографическая хореография.
- **porsche.com (Taycan model overview)** — карточки вариантов: фото в профиль + 3–4 ключевые цифры крупно (4.8 s, 300 kW) + **Compare checkbox**. **Вывод: в нашей карточке — 3 ключевых числа крупно (H, масса, L) и функция «Сравнить опоры».**
- **apple.com (macbook / vision pro)** — scroll-scrubbed видео, текст проявляется по словам, чёрный фон. Вывод: scroll-scrub — только для одной главной сцены.
- **linear.app** — тёмный, тонкие сетки, приглушённые UI-фрагменты, текст «яркое + серое» в одном абзаце. Вывод: двухтоновый абзац (важное тёмным, контекст серым).
- **locomotive.ca** — список работ гигантским засечным шрифтом с 1px линиями; изображения грузятся пикселизацией → резкость. Вывод: «pixel → sharp» reveal; список-индекс.
- **darkroom.engineering** — терминал/CRT стиль, activity log таблицей. Вывод: «журнал» в табличной типографике (у нас: таблица характеристик как инженерный лист).
- **basement.studio** — сетка 1px ячеек проявляется, «HUMAN / MACHINE» тумблер, гигантский логотип в футере.
- **14islands.com** — «Design / & / Technology» разнесённый по сетке заголовок; список «Клиент — категория серым».
- **cosmos.so** — список брендов: активный чёрный, остальные серые; поиск по цвету.
- **lusion.co / igloo.inc / activetheory.net / dogstudio / resn / unseen / immersive-g** — блокирующие прелоадеры 10–20+ секунд (на нашем канале не успели загрузиться). **Ключевой вывод для performance: никакого блокирующего прелоадера; первый экран должен быть интерактивен < 1.5 с, тяжёлое — прогрессивно.** Механику Lusion (3D-шары с физикой, WebGL-дисторсия карточек) и Igloo (камера летит сквозь ледяной кристалл по скроллу) знаю по прошлым записям — для нас избыточно.
- **hadrian / x-energy / fervo / boston dynamics / gevernova** — корпоративный «средний уровень»: карусели и карточки. Нижняя граница.
- **radiant / zaha / tesla / orsted / foster(404) / usm(не прогрузился)** — заблокированы ботозащитой.

## Волна 2 — свежие победители Awwwards 2025–2026 (энергетика / индустрия / инженерия / SOTD)
- **terminal-industries.com (SOTM)** — грузовик в закатном силуэте, текст «…connected, automated system» выезжает по словам; **аэрофото двора превращается в wireframe-разметку (computer vision overlay)**; ROI-калькулятор; панели со срезанными/вырезанными углами. Вывод: фото ↔ линейная схема одного объекта — наш главный приём (фото опоры ↔ схема КМД).
- **q-industrial.com (SOTD)** — «Industrial ⟷ Coatings»: два слова разъезжаются внутри скруглённой рамки, рамка растёт до экрана. Чёрный + красный, моно. Вывод: hero-слова разъезжаются, открывая медиа.
- **on.energy (SOTD)** — чёрный + жёлтая плашка-экран с длинным абзацем; blur-in заголовка. Минимализм.
- **breakthroughenergy.org / caeli / ciaoenergy / edolus / azero / usavionix / lidar-drone / wei / lisa.locomotive** — длинные WebGL-прелоадеры (на нашем канале > 15 с). Подтверждает правило «без блокирующего прелоадера».
- **vistaenergy.com (HM)** — графики добычи рисуются линией по скроллу, счётчики «~0 → N» анимируются. Вывод: числа, которые «докручиваются», когда попадают в кадр (24 000 т, 50+ лет, 35–750 кВ).
- **thenewindustrials.com** — полноэкранные цветные плашки сменяют друг друга, 1px сетка поверх, перспективные линии «коридора». 
- **krakenindustries.co (HM)** — топографические линии на фоне, шаги «01/02/03» в сетке, огромное «10YR» гарантия на кислотной плашке, mono. Вывод: одна большая цифра-гарантия как визуальный якорь (у нас «50+ лет» защиты цинком).
- **midlife.engineering (SOTD)** — интро: вертикальные столбцы серых оттенков (как профили проката) с оранжевыми отсечками разъезжаются; дальше **объект (синтезатор) остаётся sticky, текстовые блоки проезжают мимо**; бегущая гигантская строка внизу. Вывод: sticky-объект + проезжающие спецификации.
- **schemeengine.com (HM)** — текст на изогнутой 3D-плоскости, медиа-карточки плавают в перспективе. Слишком «шоу» для нас.
- **efla-engineers.com (HM)** — инженерная консалтинговая компания (ЛЭП!): hero «Transmission lines» с опорой на заснеженном склоне, табы-слайды внизу (01 Transmission lines / 02 …). Вывод: прямой конкурент по смыслу, но визуально стандартный — планка, которую надо перепрыгнуть.
- **hustonengineering.com (HM)** — фото промышленного узла с цветными тонировками (navy → red), затем full-bleed фото **сжимается в обрамлённую карточку** по скроллу. Вывод: «inset shrink» переход.

Вывод: прямой прототип нашей продуктовой сцены — переключатель опор, режим «КМД/рентген», цвет фона по классу напряжения.
- **cerebrium.ai (SOTD)** — sticky-список фич слева (активная тёмная, остальные бледные), справа сменяется контент. Вывод: список «Оборудование 1–6».
- **aspensearch.com (SOTD)** — швейцарская сетка ячеек, гигантская типографика, обрезанная ячейками; блоки-статистики «500+», «19+». Вывод: сетка как каркас (металлоконструкция!).
- **twks.ch (SOTD)** — абзац-манифест с «дырами» отступов, белое/чёрное. Типографика.
