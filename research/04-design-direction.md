# Этапы 4–7. Направления → выбор → UX каталога → Motion system

## Что мы знаем из исследования (входные ограничения)
1. **Изображения товара — инженерные схемы** (фронтальный вид опоры, линии + размеры), все в одном ракурсе. Это подарок: каталог можно строить как *единый чертёжный ряд*, а не как сетку фото.
2. **Фото заказчика малочисленны и низкого разрешения** (400–1100 px, часть — вырезки из слайдов, разная цветокоррекция, зима/цех). Значит: не делать сайт, зависящий от full-bleed фото. Фото — малыми форматами с единой обработкой (Varda/Huston), а «большие» визуалы — процедурные (чертёж, 3D, кристаллы цинка).
3. **Нельзя использовать** фон последнего слайда (там контакты ЗМК Энерго), логотипы партнёров — только как текст, проекты подписывать «опыт ООО «ЭК «ЭМК Энерго» в РК».
4. **Планка рынка**: сайты энергетических гигантов (Siemens Energy, GE Vernova, Hitachi, Vestas, Prysmian, EFLA) — шаблонные порталы с каруселями. Любой сайт со сторителлингом здесь выглядит «как из будущего».
5. **Тяжёлые WebGL-студии** (Lusion, Igloo, Active Theory, Dogstudio…) на среднем канале не загрузились за 15–20 с. Правило: никакого блокирующего прелоадера, первый экран живой < 1.5 с, тяжёлое — лениво.
6. **Сильнейшие механики**, подходящие предмету: чертёж→материя (Heron, Terminal), sticky-объект + проезжающие данные (Midlife, Seasats), переключатель моделей + X-RAY (Seasats), гигантское имя модели за продуктом (Rivian), линейка продуктов в одном ракурсе (Polestar), карточка «3 ключевых числа + сравнить» (Porsche), барабан категорий (Gravity), провод с физикой (Designers & Machines), кривая маска перехода (Zipline), числа докручиваются (Vista Energy).

## Этап 4. Три направления

### A. «Сборка» — чертёж становится металлом  ✅ выбрано
Идея: сайт — это путь опоры от чертежа КМД до линии в степи. Визуальный язык — чертёжный лист (тонкие линии, размерные выноски, штамп-«основная надпись» как навигационный элемент), который по ходу скролла *материализуется* в оцинкованную сталь.
- Hero: процедурная 3D-опора собирается элемент за элементом из линий чертежа → в металл (буквально «контрольная сборка» из PDF).
- Каталог: «Линейка опор» — все 112 силуэтов в реальном масштабе по высоте H, раскрытие в чертёжный лист.
- Сильная сторона: каждый эффект *рассказывает про бизнес* (КБ, КМД, сборка, цинкование). Ни у одного конкурента в регионе такого нет.
- Риск: похоже на Heron (чертёжи). Отличаемся: металл и 3D, ГОСТ-штамп, провода, цинк, не архитектура а ЛЭП.

### B. «Линия» — горизонтальное путешествие вдоль ВЛ
Весь сайт — одна горизонтальная ЛЭП от Караганды; опоры проходят мимо, между ними секции. Каталог — сами опоры на линии.
- Сильно как метафора, но: горизонтальный скролл на всю страницу утомляет, плохо на мобильных, ломает привычную навигацию, сложно с доступностью. Берём только как приём внутри каталога (ряд опор) и провода-разделители.

### C. «Цинк» — материальность
Серебристо-белая палитра, макро-текстура цинкового «спанглa» (кристаллы горячего цинкования), 3D-деталь крупным планом, свет скользит по металлу.
- Очень дорого выглядит, но мало связи с каталогом и с масштабом (35–750 кВ). Берём как одну сцену (секция «50+ лет защиты»).

### Выбор
**A как основа + провода из B + сцена цинка из C.** Одна история: *чертёж → сборка → цинк → линия → ваш объект*.

## Визуальная система

### Палитра (светлая, «инженерный день»)
Не синяя (презентация), не сине-серая (конкурент), не кремовая (AI-штамп), не чёрная.
| Токен | Hex | Роль |
|---|---|---|
| `--paper` | `#EEF0EE` | основной фон: холодная чертёжная бумага / пасмурное небо над степью |
| `--paper-2` | `#E3E6E4` | вторичные плоскости, ячейки сетки |
| `--zinc` | `#B9C0C3` | оцинкованная сталь: линии сетки, неактивные элементы |
| `--steel` | `#5E676D` | второстепенный текст, размерные линии |
| `--graphite` | `#1C2226` | основной текст, металл в тени, линии чертежа |
| `--signal` | `#F5C400` | единственный акцент: жёлтый знака «Осторожно, электрическое напряжение» — маркеры, активные состояния, курсор, провод под током |
Акцент используется точечно (≤ 3% площади). На жёлтом — только графит.

### Типографика
- **Geologica** (variable, кириллица, ось Sharpness) — заголовки и интерфейс. Технический гротеск с «рублеными» терминалами, не Inter/Manrope-стандарт. Заголовки крупные, плотные (−2% трекинг), без капса-лейблов над каждым блоком.
- **IBM Plex Mono** — *только* размерные выноски на чертежах и значения в таблицах характеристик (это действительно чертёжная аннотация, а не декор).
- Числа — табличные цифры (`font-variant-numeric: tabular-nums`).
- Самостоятельный хостинг woff2 (subset latin+cyrillic), `font-display: swap`.

### Форма
- Срезанные углы 45° (chamfer) у медиа и панелей — как у листового проката/фасонок; никаких «пилюль-карточек со скруглением 24px».
- Линии 1px цвета `--zinc` = несущая сетка («металлоконструкция страницы»).
- Штамп («основная надпись» ГОСТ 2.104) — внизу справа экрана в hero и в карточке опоры: Наименование / Лист / Масштаб — живой индикатор прогресса и масштаба.

## Этап 6. UX каталога — «Линейка опор»

### Обзор (каталог в странице)
```
┌───────────────────────────────────────────────────────────────┐
│ Линейка опор             35  110 [220] 330  500 кВ   ⌕ П110-… │  ← барабан/табы класса напряжения + поиск
│ Промежуточные · Анкерно-угловые · Все           112 → 26 опор │
│                                                               │
│  50 м ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  │  ← шкала высот (реальная)
│            ╱╲      ╱╲                                         │
│  30 м ─ ─ ╱┼┼╲ ─ ─╱┼┼╲─ ─ ╱╲ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  │
│     ╱╲   ╱┼┼┼┼╲  ╱┼┼┼┼╲  ╱┼┼╲   ╱╲  …  (горизонтальный ряд,   │
│ 🧍 ╱┼┼╲ ╱┼┼┼┼┼┼╲╱┼┼┼┼┼┼╲╱┼┼┼┼╲ ╱┼┼╲    драг/скролл/свайп)    │
│ ═══════════════════════════════════════════════════════════  │  ← земля
│  П110-1  П110-2   1У110-1  …                                  │
└───────────────────────────────────────────────────────────────┘
```
- Все силуэты (вырезаны из оригинальных схем) стоят на одной земле **в реальном масштабе по H** + человек 1,8 м для масштаба. Это сразу показывает «масштаб компании» без слов.
- Между опорами провисают провода (цепная линия) — ряд читается как настоящая ВЛ.
- Hover: опора «под напряжением» — силуэт графит → жёлтый маркер на вершине, поднимается подпись (имя, H, масса), соседние бледнеют.
- Фильтр класса напряжения: опоры, не попавшие в фильтр, «опускаются» под землю (clip по линии земли), оставшиеся съезжаются (GSAP Flip). Не исчезновение, а физическое действие.
- Переключатель вида: «Линейка» ↔ «Таблица» (плотный список для инженеров: имя, кВ, H, h, L, масса, проект) — инженеру нужна скорость, не только шоу.
- Поиск по марке (П110-2 → прыжок к опоре).
- Мобильные: ряд — горизонтальный свайп со snap; фильтры — сегмент-контрол; таблица — карточки-строки.

### Раскрытие опоры — «Чертёжный лист»
Последовательность (≈ 900 мс, всё прерываемо):
1. 0 мс — клик: силуэт фиксирует позицию (FLIP first).
2. 0–450 мс — силуэт *физически* летит и растёт в левую половину экрана (ease-in-out сильный); остальной ряд уходит вниз под землю и размывается; фон превращается в лист с рамкой ГОСТ (рамка рисуется по периметру stroke-dashoffset).
3. 300–700 мс — силуэт кроссфейдом сменяется **оригинальной схемой 1:1** (именно изображение конкурента, как требует ТЗ); за ней выезжает гигантское имя «П110-2» (Rivian), обрезанное листом.
4. 450–900 мс — справа строка за строкой печатается таблица характеристик (stagger 40 мс), ключевые числа H / масса / L докручиваются от 0.
5. Параллельно: вдоль чертежа рисуется *наша* размерная линейка H (от земли до вершины) с подписью «H = 31,0 м», и рядом возникает фигура человека 1,8 м в том же масштабе.
6. Штамп внизу справа заполняется: Наименование, Класс напряжения, «Лист 14 из 112».
- Навигация внутри: ← / → (клавиши, свайп, кнопки) — опора уезжает влево, следующая выезжает справа, лист остаётся (как Seasats). Не нужно закрывать, чтобы листать.
- «Сравнить»: добавить до 3 опор; режим сравнения ставит их рядом на одну землю в общем масштабе + таблица различий.
- Закрытие: Esc / крестик / свайп вниз — обратная анимация в своё место в ряду.
- URL обновляется (`#/opora/p110-2`), ссылкой можно поделиться, «Назад» закрывает.
- CTA в листе: «Запросить расчёт по П110-2» — подставляет марку в форму заявки.

## Этап 7. Motion system

### Принципы
1. **Движение = производственный процесс.** Каждое ключевое движение — метафора: черчение, сборка, цинкование, натяжение провода, монтаж.
2. **Одна сильная сцена на экран.** Никаких fade-up на каждом блоке. Тексты появляются вместе со своей сценой.
3. **Скролл управляет временем** только там, где есть процесс (сборка опоры, кристаллизация цинка, прокладка линий на карте). Остальное — реакция на действия.
4. **Прерываемость**: всё, что запускает пользователь, — transitions/Flip, а не keyframes.

### Кривые и длительности (токены)
```
--ease-out:    cubic-bezier(0.23, 1, 0.32, 1)     входы, раскрытия
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1)    перемещения по экрану (Flip)
--ease-draw:   cubic-bezier(0.65, 0, 0.35, 1)     прорисовка линий
UI-отклик 120–200 мс · раскрытие листа 900 мс · сцены — скролл-скраб (Lenis, lerp 0.1)
```

### 5 фирменных паттернов
| # | Паттерн | Где | Технология |
|---|---|---|---|
| 1 | **Сборка опоры**: линии чертежа → элементы прилетают и встают на место → металл с бликами; камера облетает | Hero (pinned ~250vh) | Three.js, InstancedMesh из L-уголков, MeshStandardMaterial (metalness), RoomEnvironment; GSAP ScrollTrigger scrub |
| 2 | **Провода**: цепные линии с пружинной физикой, «дзинь» при пересечении курсором; ток бежит по проводу жёлтым импульсом при hover CTA | Разделители секций, ряд каталога, hero | Canvas 2D / SVG path, verlet-интегратор |
| 3 | **Линейка → Чертёжный лист** | Каталог | GSAP Flip, clip-path, SVG stroke-dashoffset |
| 4 | **Кристаллизация цинка**: Voronoi-«спанглы» прорастают и вспыхивают бликом | Секция «50+ лет» | WebGL фрагментный шейдер (или Canvas fallback) |
| 5 | **Прокладка линий**: маршруты ВЛ прокладываются по карте Казахстана, опоры встают точками | «Опыт» | SVG path + stroke-dashoffset scrub |
Плюс: манифест миссии подсвечивается по словам при чтении (скролл), числа докручиваются при входе в кадр, курсор-прицел с координатами на чертежах (только desktop).

### Мобильная хореография (отдельная, не уменьшенная)
- Hero: та же сборка, но короче (150vh), меньше элементов, камера без облёта; DPR ≤ 1.5.
- Каталог: свайп-ряд со snap; лист — полноэкранный bottom-sheet, свайп влево/вправо между опорами, свайп вниз — закрыть.
- Провода: без физики курсора, лёгкое покачивание от гироскопа нет — только скролл-импульс.
- Цинк: статичный кадр шейдера, анимация только при видимости.
- `prefers-reduced-motion`: сборка — сразу собранная опора, кроссфейды вместо полётов, без скролл-скраба.

### Performance-бюджет
- Первый экран: HTML+CSS+шрифты+лёгкий JS < 150 KB gz; Three.js грузится после первого кадра (динамический import), до этого — SVG-постер опоры.
- Изображения: AVIF/WebP, `srcset`, lazy; силуэты — PNG-8/WebP с альфой, спрайт-подгрузка по мере прокрутки ряда.
- Канвасы рендерят только в видимой зоне (IntersectionObserver), DPR clamp, пауза при `visibilitychange`.
- Без блокирующего прелоадера.
