# Сайт ТОО «Энергоконструкция»

Одностраничный сайт: Vite + TypeScript, GSAP (ScrollTrigger, Flip), Lenis, Three.js (лениво), без фреймворка.

## Запуск
```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/ (статические файлы, можно положить на любой хостинг)
npm run preview    # просмотр сборки на http://localhost:4319
npm run data       # пересобрать данные каталога, фото и карту из ../research
```

## Откуда контент
- **О компании** — только из презентации `ТОО_Энергоконструкция_презентация.pdf` (выжимка: `../research/01-client.md`).
- **Каталог опор (112 позиций)** — названия и характеристики из раздела «Металлические опоры ВЛ» сайта aspmk-519.kz (`src/data/catalog.json`).
  - **Чертежи** перерисованы в вектор 1:1 (`public/catalog/<slug>.svg`, скрипт `scripts/trace.py`): обводятся слои схемы — элементы опоры и все размеры (размерные и выносные линии, стрелки, цифры, H/h/L). Водяной знак и фон отброшены, цвета приведены к палитре сайта. Для «Линейки» и сравнения используется вариант только с опорой (`<slug>-t.svg`).
  - В источнике потерян символ диапазона в марках проводов («АС-70 ? АС-95») — при переносе заменён на «÷».
  - У опоры 1П35-2 в источнике масса «20,89 кг» — перенесено как есть, стоит уточнить.
- **Фото** — вырезаны из слайдов PDF и приведены к единой цветокоррекции (`scripts/build_photos.py`).
- **Карта опыта** — схема: трассы проведены прямыми между пунктами из названий проектов (подписано на сайте).

## Форма заявки
В презентации нет e-mail, поэтому по умолчанию форма собирает текст заявки и предлагает позвонить или скопировать его.
Чтобы заявки уходили автоматически, укажите адрес обработчика (любой сервис, принимающий POST JSON: свой backend, Formspree, Telegram-бот и т.п.):
```html
<form class="form" data-form data-endpoint="https://example.com/api/request" novalidate>
```
Поля: `name`, `company`, `phone`, `message`.

## Структура
- `src/hero/` — сцена «Сборка»: SVG-чертёж (`hero.ts`) → 3D-опора из L-уголков (`scene.ts`, Three.js, грузится при первом взаимодействии).
- `src/tower/model.ts` — процедурная модель опоры (общая для SVG и 3D). Это иллюстрация, не конкретная марка.
- `scripts/trace.py` — векторная перерисовка чертежей опор 1:1.
- `src/catalog/` — «Линейка опор» (масштаб по H, фильтр по кВ, поиск, таблица, мини-карта), «Чертёжный лист» (`sheet.ts`), сравнение (`compare.ts`). Ссылка на опору: `#/opora/<slug>`.
- `src/ui/` — провода с физикой (`wires.ts`), шейдер цинка (`zinc.ts`), карта (`map.ts`), форма, секции.
- `src/styles/main.css` — токены и все стили.
